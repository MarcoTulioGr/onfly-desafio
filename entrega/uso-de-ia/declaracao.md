# Declaração de uso de IA

## Ferramenta e modelo

- Ferramenta: Claude (app do claude.ai)
- Modelo: Claude Opus 5.5

## Por que usei

Tenho mais experiência com C# do que com Python. Usei a IA principalmente como professora:
para aprender os recursos de Python que o desafio usa, comparando com o que eu já conhecia
de C#, e para revisar meu raciocínio, meu código e meus textos.

## O que a IA fez

- **Prompt inicial:** pedi que ela atuasse como professora de desenvolvimento para um
  estagiário.Segue o prompt: "ZIP
Atue como um professor desenvolvedor de software para alunos em nível estagiário que esta fazendo desafios! Tenho mais experiência com C# do que com Pytho, por isso, ensine, dê dicas e ao final desse desafio, devemos ter um repositório publico no github com este desafio completo e praticamente sem erros. Utilize uma linguagem de fácil entendimento e uma boa didática comparando com C#."
- **Artefato:** criou o documento "Roteiro de Python para o desafio Onfly", com 7 módulos
  de estudo (fundamentos, ordenação, datas, `Decimal`, CSV/argparse, classes e pytest),
  exemplos, exercícios e a comparação de cada exemplo com C#.
- **Na documentação:** propôs a estrutura do `README-ENTREGA.md` e revisou e reescreveu
  trechos que eu escrevi.
- **Conferência final:** com a minha autorização, acessou a pasta do projeto no meu
  computador para rodar os testes e comparar as alterações com o código original.

## O que eu fiz

- Estudei Python pelo roteiro e fiz os exercícios de cada módulo, errando, lendo as
  mensagens de erro e corrigindo.
- Para cada defeito, escrevi primeiro a minha própria versão da função a partir da regra
  do README e comparei com a do projeto para identificar o erro.
- Apliquei as 5 correções no projeto original, uma por vez, rodando o `pytest` a cada
  etapa, com um commit por defeito na branch `fix/corrige-relatorio`.
- Escrevi os testes de `tests/test_extra.py` e fiz a prova: o teste das 200 linhas
  falha com o limite de volta e passa sem ele.
- Configurei o ambiente, criei o repositório e a branch, fiz os commits, o push e o
  Pull Request.
- Escrevi o `README-ENTREGA.md` a partir das minhas anotações, ajustando com as revisões
  da IA, e validei o relatório real e a amostra do README.
